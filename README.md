# 🎓 UniWise Student — AI-Powered University Student Assistant

**Day 14 of the 30 Days AI Automation Challenge**

UniWise Student is an AI-powered university assistant designed to help students organize academic tasks, identify priorities, and receive personalized advisory guidance.

The project combines a modern web frontend with an **n8n automation workflow** and AI processing to create a practical university-focused automation system.

## 💡 Problem

University students often have multiple assignments, quizzes, exams, projects, and deadlines at the same time. It can become difficult to determine what should be handled first and how to manage academic workload effectively.

UniWise addresses this problem by allowing students to submit their academic task information and receive an AI-generated advisory response.

## 🔄 Automation Workflow

The UniWise automation workflow follows these steps:

1. Student enters academic task details.
2. Student selects the priority level.
3. Frontend sends the information to the n8n webhook.
4. n8n receives and processes the request.
5. AI analyzes the submitted academic information.
6. An advisory response is generated.
7. n8n returns the response to the frontend.
8. UniWise displays the advisory to the student.
